## 💻 Open-Source GitHub Projects

Below are top open-source projects for building air quality hardware, parsing sensor telemetry, calculating standard EPA/EU AQIs, and analyzing atmospheric data.

[![OpenAQ Stars](https://img.shields.io/github/stars/openaq/openaq-fetch?style=social&color=white)](https://github.com/openaq/openaq-fetch/stargazers) **[OpenAQ Fetch / Platform](https://github.com/openaq/openaq-fetch)**  
Open-source data ingestion pipeline and APIs for aggregating air quality measurements worldwide from government and low-cost sensor networks.

[![Sensor.Community Stars](https://img.shields.io/github/stars/opendata-stuttgart/sensors-software?style=social&color=white)](https://github.com/opendata-stuttgart/sensors-software/stargazers) **[Sensor.Community (Luftdaten Firmware & Stack)](https://github.com/opendata-stuttgart/sensors-software)**  
Global citizen science project providing open firmware (ESP8266/ESP32) and backend map APIs for DIY PM2.5 / PM10 particulate sensors.

[![openair Stars](https://img.shields.io/github/stars/davidcarslaw/openair?style=social&color=white)](https://github.com/davidcarslaw/openair/stargazers) **[openair](https://github.com/davidcarslaw/openair)**  
R package for analyzing air quality data, trend analysis, directional wind roses, and atmospheric dispersion analysis widely used by academia and regulatory agencies.

[![awesome-air-quality Stars](https://img.shields.io/github/stars/openaq/awesome-air-quality?style=social&color=white)](https://github.com/openaq/awesome-air-quality/stargazers) **[Awesome Air Quality (OpenAQ Ecosystem)](https://github.com/openaq/awesome-air-quality)**  
Community curated list of open source air quality software libraries, wrappers, open datasets, and hardware tools.

[![PyEPR Stars](https://img.shields.io/github/stars/PfisterLab/pyepr?style=social&color=white)](https://github.com/PfisterLab/pyepr/stargazers) **[pyepr / python-aqi](https://github.com/twaang/python-aqi)**  
Python library for calculating US EPA Air Quality Index (AQI) values from raw pollutant concentration data (PM2.5, PM10, O3, NO2, CO, SO2).

[![airq Stars](https://img.shields.io/github/stars/fortunto2/airq?style=social&color=white)](https://github.com/fortunto2/airq/stargazers) **[airq CLI](https://github.com/fortunto2/airq)**  
Command-line tool to check real-time air quality index and weather data directly from terminal using open APIs.

[![esp32-air-quality Stars](https://img.shields.io/github/stars/Sensirion/arduino-gas-index-algorithm?style=social&color=white)](https://github.com/Sensirion/arduino-gas-index-algorithm/stargazers) **[Sensirion Arduino Gas Index Algorithm](https://github.com/Sensirion/arduino-gas-index-algorithm)**  
Official open-source C++ library to calculate VOC and NOx indices for Sensirion environmental sensors on microcontrollers.

## 💡 Ecosystem Breakdown & Architecture Guide
- **Global Open Data Backbone**: Use **OpenAQ** for harmonized station data across 100+ countries.
- **Citizen Sensing**: Flash **Sensor.Community** firmware onto ESP32 + SDS011 / BME280 hardware for low-cost dense spatial coverage.
- **Data Analytics & Research**: Utilize **openair (R)** or **python-aqi (Python)** for regulatory reporting and trend analysis.
- **Enterprise Integration**: Combine OpenAQ open baselines with **Google BreezoMeter** or **Ambee** APIs when high-resolution satellite interpolation or strict SLAs are required.
